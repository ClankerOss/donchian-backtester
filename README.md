# Donchian breakout backtesting research

My **first attempt at Monte Carlo simulation, started in late 2025**. This exploratory Python project investigates a **Donchian breakout** strategy using hourly BTC/USD data, in-sample parameter search, an experimental walk-forward function, and Monte Carlo price-bar permutation tests. The repository also contains exploratory moving-average and decision-tree scripts and a **separate** Databento example for ES futures data. This repository documents an early learning project, including unfinished experiments and methodological limitations. It is **not** a production trading system or evidence of a profitable strategy.

## Files

| File | Purpose |
| --- | --- |
| `donchian.py` | Donchian breakout signals, lookback optimization and experimental walk-forward function; plots an in-sample equity curve. |
| `insample_donchian_mcpt.py` | In-sample Monte Carlo permutation test for the optimized Donchian profit factor. |
| `bar_permute.py` | OHLC price-bar permutation helper and exploratory examples. |
| `moving_average.py` | Moving-average research example. |
| `tree_strat.py`, `insample_tree_mcpt.py` | Exploratory decision-tree strategy and permutation test. |
| `GetMarketData.py` | Downloads hourly BTC-USD OHLCV data via `yfinance` and saves `BTCUSD3600.pq`. |
| `DonchainWFutures.py` | **Separate** Databento historical-data example: daily OHLCV for continuous ES futures symbols. It does not feed the BTC Donchian backtest. |

## Data structure

### BTC/USD hourly dataset (`BTCUSD3600.pq`)

Generated by running `GetMarketData.py`, which requests the `BTC-USD` ticker from Yahoo Finance using `interval='1h'` and `period='2y'`. The script flattens any multi-level column names, converts them to lowercase, names the datetime index `timestamp`, and writes a Pandas **Parquet** file. Expected structure:

| Field | Type / meaning |
| --- | --- |
| Index: `timestamp` | Datetime index; one row per hourly bar (subject to provider availability). |
| `open` | Opening BTC/USD price for the bar. |
| `high` | Highest BTC/USD price during the bar. |
| `low` | Lowest BTC/USD price during the bar. |
| `close` | Closing BTC/USD price; **required** by the Donchian strategy. |
| `volume` | Traded volume reported by the data provider. |

The downloaded file may also contain provider-specific fields. `donchian.py` primarily uses `close`; `bar_permute.py` expects OHLC data. The scripts assume hourly bars when using lookback values such as `24`.

**Important data-window mismatch:** `GetMarketData.py` requests only the most recent two years, while some research scripts filter for `2016 <= year < 2020` or default to four years of hourly training data. Those filters may produce empty datasets with freshly downloaded data. Adjust the dates and training window to match data you are legally permitted to access before running the analyses. The exact coverage of an existing local Parquet file must be checked independently.

### ES futures data (Databento)

`DonchainWFutures.py` queries Databento dataset `GLBX.MDP3` with `schema='ohlcv-1d'`, `stype_in='continuous'`, and continuous symbols `ES.n.0` and `ES.n.1` starting from `2024`. The response is converted to a Pandas DataFrame; the script groups by `symbol` and plots the `close` field. It does **not** save a Parquet file or feed the Donchian scripts. This is **daily** futures data, not the hourly BTC/USD data above. Databento access and data licensing may be required.

## Setup and execution

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
python GetMarketData.py
python donchian.py
```

The last command may require updating the hard-coded date filter in `donchian.py` to match the downloaded data. `insample_donchian_mcpt.py` also requires defining `train_df` (currently commented out). These research scripts have **not** been presented as tested end-to-end.

To run the separate ES example, edit `DonchainWFutures.py` and replace `INSERTDATABENTOAPIHERE` with a valid Databento API key **locally**. **Do not commit your real key.** A safer future improvement is loading the key from an environment variable.

## Research limitations

- `donchian.py`'s current `walkforward_donch` function does **not** re-optimize at every intended training step: its re-optimization condition should be fixed before reporting walk-forward results.
- The example `donchian.py` plot is **in-sample**, not independently validated out-of-sample performance.
- Backtest calculations do not model transaction costs, commissions, slippage, funding, or execution constraints.
- Profit factor and permutation tests are exploratory and should not be interpreted as evidence of live profitability.

## Security and publishing

The included `.gitignore` excludes `.env` files, Parquet/CSV/DBN datasets and other local market data. The provided `BTCUSD3600.pq` file is intentionally **not** included in this repository archive. Do not upload proprietary market data or credentials. **Rotate the Databento key previously hardcoded in the source, even though it has been replaced here.** Check `git status` and staged changes before publishing.
