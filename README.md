# donchian-backtester

Systematic backtesting framework for Donchian channel breakout strategies on futures markets.

Implements Monte Carlo simulation to stress-test strategy robustness across thousands 
of randomised market scenarios before any live deployment.

## What this repo contains
- Backtest engine architecture and methodology overview
- Performance metrics and statistical analysis approach
- Documentation of the Monte Carlo simulation framework

## Why files are not public
The full implementation is proprietary and in active use through 
[Monolith Quant](https://www.monolithquant.com). I don't open-source 
strategies I'm actively trading.

## Tech stack
Python · Pandas · NumPy · Monte Carlo Simulation · CME Futures
